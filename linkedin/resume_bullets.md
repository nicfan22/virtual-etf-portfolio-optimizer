# Resume Bullets

## Full Version

**Virtual ETF Portfolio Optimization & Risk Management Engine**  
Python, Streamlit, Pandas, NumPy, SciPy, Scikit-learn, Plotly, yFinance

- Built an editable ETF allocation and risk analytics web app that optimizes multi-asset portfolios using constrained optimization, risk parity, maximum Sharpe, minimum volatility, and maximum diversification methods.
- Designed a walk-forward backtesting framework that uses only historical data available at each rebalance date, reducing look-ahead bias and creating a more realistic research workflow.
- Implemented simulated transaction costs using portfolio turnover and compared strategy performance against SPY and 60/40 benchmarks.
- Generated institutional performance analytics including CAGR, annualized volatility, Sharpe ratio, Sortino ratio, max drawdown, Calmar ratio, VaR, CVaR, alpha, beta, correlation, and turnover.
- Built interactive Plotly dashboards and a deployable Streamlit application with editable portfolio assumptions and a LinkedIn-shareable project URL.
